# ReelMotion — Studio Konten & Video AI Otomatis

Buat video AI otomatis dari satu topik:
- **Faceless Vertikal (9:16)** & **Faceless Horizontal (16:9)** — Naskah otomatis, suara narator AI (`VoxCPM2`), gambar AI (`Z-Image Turbo`), dan subtitle menyala per kata (`Stable-Whisper`).
- **Motion Graphic AI (10s–120s)** — Animasi grafis bergerak: teks, ikon, grafik, dan tokoh untuk iklan produk & video penjelasan.
- **AudioBook** — Ubah naskah cerita atau buku menjadi episode audiobook bertampilan video per episode.
- **AutoClipper** — Tempel tautan video YouTube panjang, AI mencarikan momen terbaik dan memotongnya jadi klip vertikal.

## Menjalankan Lokal

```bash
npm install
npm run dev
```

## Build Produksi

```bash
npm run build
```
